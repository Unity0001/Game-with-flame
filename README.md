# 🎮 Clone do Color Switch com Flutter & Flame

Este projeto é uma **réplica do jogo Color Switch**, desenvolvida utilizando o framework **Flutter** e o motor de jogos **Flame Engine**. O jogador controla uma bola colorida que deve passar por obstáculos giratórios combinando com a cor correta, desafiando seus reflexos e atenção.

## 📱 Tecnologias Utilizadas

- [Flutter](https://flutter.dev/) — Framework para desenvolvimento de apps multiplataforma
- [Flame](https://flame-engine.org/) — Motor de jogos 2D para Flutter
- [Dart](https://dart.dev/) — Linguagem de programação

## 🎮 Funcionalidades

- Controle por toque para movimentar a bola
- Obstáculos coloridos em rotação
- Detecção de colisão baseada em cores
- Sistema de pontuação e progressão de dificuldade
- Tela de início, game over e reinício
- Transições suaves e animações

## ▶️ Como Executar

### Pré-requisitos

- Flutter instalado (3.0 ou superior)
- Emulador ou dispositivo físico Android/iOS

### Passos para rodar o projeto

```bash
# Clone este repositório
git clone https://github.com/seu-usuario/color-switch-flutter.git
cd color-switch-flutter

# Instale as dependências
flutter pub get

# Execute o app
flutter run
